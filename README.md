
# harmoni-poa-pre02-analysis

Análisis de datos del ensayo PRE-02 (*Velocity Determination*) del actuador
LPOA1S-EM-RT-PRE02, correspondiente al Pick-Off Arm del subsistema NGSS de
HARMONI (ELT), realizado durante mis prácticas extracurriculares en el
Centro de Astrobiología (CAB, CSIC-INTA).

## Contenido
- `analisis_def_reorganizado.ipynb`: segmentación de los datos en ciclos de subida/bajada,
  seguimiento de velocidad, comportamiento dinámico (arranque y frenada)
  e histéresis en el punto de origen.

## Requisitos
Python 3, `numpy`, `pandas`, `matplotlib`, `scipy`.

*Los datos del ensayo no se incluyen en este repositorio.*
